# 📝 문제와 보기, 해설 입력 방법 (간단 가이드)

**코딩을 몰라도 괜찮습니다!** 아래 두 가지 방법 중 편한 방법을 선택하세요.

---

## 🎯 방법 1: 엑셀로 입력하기 (많은 문제 입력 시 추천!)

### 1️⃣ 엑셀 파일 만들기

**엑셀이나 구글 스프레드시트**를 열고 다음과 같이 입력하세요:

#### 첫 번째 줄 (열 제목):
```
시험유형 | 시험년도 | 문제번호 | 카테고리 | 문제내용 | 선택지1 | 선택지2 | 선택지3 | 선택지4 | 선택지5 | 정답 | 해설 | 판례 | 키워드 | 난이도
```

#### 두 번째 줄부터 (예시):
```
변호사시험 | 2023 | 1 | 형법총론 | 다음 중 옳은 것은? | ... | ... | ... | ... | (비움) | 4 | 해설내용... | 대법원판례 | 키워드1,키워드2 | 보통
```

### 2️⃣ 각 열에 넣을 내용

| 항목 | 입력 내용 | 예시 |
|-----|---------|-----|
| **시험유형** | `공무원`, `변호사시험`, `사법시험`, `연습문제` | `변호사시험` |
| **시험년도** | 숫자 (YYYY) | `2023` |
| **문제번호** | 숫자 | `1` |
| **카테고리** | 한글 자유 입력 | `형법총론` |
| **문제내용** | 문제 전체 텍스트 | `다음 중...` |
| **선택지1~4** | 각 보기 내용 (필수) | `형법은...` |
| **선택지5** | 5지선다만 입력, 4지선다는 비워두기 | *(비워두기)* |
| **정답** | 정답 번호 (1~5) | `4` |
| **해설** | 상세 해설 | `이 문제는...` |
| **판례** | 관련 판례 (선택) | `대법원 2008도10479` |
| **키워드** | 쉼표로 구분 | `행위시법,소급효` |
| **난이도** | `쉬움`, `보통`, `어려움`, `전문가` | `보통` |

### 3️⃣ 파일 저장

- 파일명: **형법문제_2023.xlsx** (원하는 이름)
- 형식: **Excel (.xlsx)**
- 구글 스프레드시트는: `파일 > 다운로드 > Microsoft Excel`

### 4️⃣ 개발자에게 전달

저장한 파일을 개발자에게 주고 다음과 같이 요청:

```
"이 엑셀 파일의 문제들을 데이터베이스에 추가해주세요"
```

**개발자 실행 명령어:**
```bash
cd backend
npm install xlsx  # 처음 한 번만
npm run seed:questions 형법문제_2023.xlsx
```

**샘플 문제 생성 (테스트용):**
```bash
npm run seed:questions sample
```

## 🌐 방법 2: 웹 페이지에서 입력하기 (1-2개 문제 급할 때)

### 1️⃣ 관리자 페이지 접속

1. 형법 마스터 웹사이트 접속
2. 관리자로 로그인
3. **"문제 관리"** > **"새 문제 추가"** 클릭

### 2️⃣ 양식 채우기

화면에 나오는 양식을 순서대로 입력:

- 시험 유형, 년도, 문제번호
- 카테고리, 난이도
- **문제 내용** (큰 텍스트 박스)
- **선택지 1~5** (4개는 필수, 5번은 선택)
- **정답 선택** (드롭다운)
- **해설** (상세하게)
- 판례, 키워드 (선택사항)

### 3️⃣ 저장

- **"문제 추가하기"** 버튼 클릭
- 성공 메시지 확인!

## 💡 작성 팁

### 문제 내용 작성
- ✅ 명확하고 간결하게
- ✅ 법 조문은 정확하게
- ✅ 학생들이 이해하기 쉽게

### 선택지 작성
- ✅ 비슷한 길이로
- ✅ 너무 쉬운 오답은 피하기
- ✅ 혼동하기 쉬운 개념 활용

### 해설 작성 ⭐
- ✅ **각 선택지별로 설명** (①②③④ 번호 사용)
- ✅ 정답과 오답의 이유 모두 설명
- ✅ 관련 법 조문과 판례 인용
- ✅ 핵심 개념 강조

**해설 예시:**
```
형법 제1조 제2항은 "범죄 후 법률의 변경에 의하여..." 규정하고 있습니다.

① 형법 제1조 제2항 전문에 해당합니다. (정답)
② 형법 제1조 제3항에 해당합니다.
③ 형법은 원칙적으로 행위시법주의를 취합니다.
④ 틀렸습니다. 신법이 중한 경우 구법을 적용합니다.
```

## ❓ 자주 묻는 질문

**Q: 구글 스프레드시트 사용 가능한가요?**
→ 네! 작성 후 Excel 형식(.xlsx)으로 다운로드하세요.

**Q: 선택지가 4개만 있으면?**
→ 선택지5 칸은 비워두세요.

**Q: 문제에 줄바꿈을 하려면?**
→ 엑셀: `Alt+Enter` (Windows) / `Option+Enter` (Mac)
→ 웹: 그냥 Enter

**Q: 실수로 틀린 문제를 입력했어요.**
→ 개발자에게 문의 (시험유형, 년도, 문제번호 알려주기)

**Q: 한 번에 몇 개까지 입력 가능?**
→ 제한 없음. 하지만 처음엔 10-20개로 테스트 추천

**Q: 엑셀 vs 웹, 뭐가 더 좋나요?**
→ **엑셀**: 10개 이상 많은 문제
→ **웹**: 1-2개 급한 문제
