# 📝 문제 입력 가이드 (비개발자용)

코딩을 몰라도 엑셀만 다룰 수 있으면 문제를 쉽게 입력할 수 있습니다!

## 🎯 방법 1: 엑셀 파일로 문제 입력하기 (추천!)

### 1단계: 엑셀 파일 준비

엑셀이나 구글 스프레드시트를 열고 다음과 같이 열을 만드세요:

| 시험유형 | 시험년도 | 문제번호 | 카테고리 | 문제내용 | 선택지1 | 선택지2 | 선택지3 | 선택지4 | 선택지5 | 정답 | 해설 | 판례 | 키워드 | 난이도 |
|---------|---------|---------|---------|---------|--------|--------|--------|--------|--------|-----|-----|-----|-------|-------|

### 2단계: 각 열에 맞게 내용 입력

#### 📌 시험유형
- `공무원` 또는 `변호사시험` 또는 `사법시험` 또는 `연습문제`
- **예시**: `변호사시험`

#### 📌 시험년도
- 숫자로 입력
- **예시**: `2023`

#### 📌 문제번호
- 숫자로 입력
- **예시**: `1`

#### 📌 카테고리
- 문제의 분류 (한글로 자유롭게)
- **예시**: `형법총론`, `형법각론`, `형사소송법`

#### 📌 문제내용
- 전체 문제 텍스트를 입력
- 줄바꿈이 필요한 경우 그대로 입력하세요
- **예시**:
```
다음 중 형법의 시간적 적용범위에 관한 설명으로 옳지 않은 것은?
```

#### 📌 선택지1 ~ 선택지5
- 각 선택지의 내용을 입력
- 선택지5는 5지선다인 경우에만 입력 (4지선다면 비워두세요)
- **예시**:
  - 선택지1: `범죄 후 법률의 변경에 의하여 그 행위가 범죄를 구성하지 아니하거나 형이 구법보다 경한 때에는 신법에 의한다.`
  - 선택지2: `재판확정 후 법률의 변경에 의하여 그 행위가 범죄를 구성하지 아니한 때에는 형의 집행을 면제한다.`

#### 📌 정답
- 정답 번호를 숫자로 입력 (1, 2, 3, 4, 5 중 하나)
- **예시**: `4`

#### 📌 해설
- 문제에 대한 상세한 해설
- 각 선택지에 대한 설명을 포함하면 좋습니다
- 줄바꿈을 사용해서 보기 좋게 작성하세요
- **예시**:
```
형법 제1조 제2항은 "범죄 후 법률의 변경에 의하여 그 행위가 범죄를 구성하지 아니하거나 형이 구법보다 경한 때에는 신법에 의한다"고 규정하여 피고인에게 유리한 소급효를 인정하고 있습니다.

① 형법 제1조 제2항 전문에 해당합니다.
② 형법 제1조 제3항에 해당합니다.
③ 형법은 원칙적으로 범죄 시의 법률을 적용하는 행위시법주의를 취하고 있습니다.
④ 틀렸습니다. 신법이 구법보다 형이 중한 경우 구법을 적용합니다.
```

#### 📌 판례 (선택사항)
- 관련 판례가 있으면 입력 (없으면 비워두세요)
- **예시**: `대법원 2008도10479 판결`

#### 📌 키워드
- 문제와 관련된 키워드를 쉼표(,)로 구분해서 입력
- **예시**: `행위시법,소급효금지,형법총론,시간적적용범위`

#### 📌 난이도
- `쉬움` 또는 `보통` 또는 `어려움` 또는 `전문가` 중 하나
- **예시**: `보통`

## 🚀 엑셀 파일을 데이터베이스에 업로드하는 방법

### 1단계: 엑셀 파일 저장
- 파일 이름: `형법문제_2023.xlsx` (원하는 이름으로)
- 저장 위치: `backend` 폴더 안에 저장

### 2단계: 명령어 실행 (개발자에게 요청)
개발자에게 다음을 요청하세요:

```bash
cd backend
npm run seed:questions 형법문제_2023.xlsx
```

**또는 처음 테스트할 때는 샘플 문제로 시작:**

```bash
cd backend
npm run seed:questions sample
```

## 🎯 방법 2: 관리자 페이지에서 직접 입력 (개발 예정)

나중에 관리자 페이지가 만들어지면 웹 브라우저에서 바로 문제를 입력할 수 있습니다!

1. 관리자로 로그인
2. "문제 관리" 메뉴 클릭
3. "새 문제 추가" 버튼 클릭
4. 양식에 맞춰 입력
5. "저장" 버튼 클릭

## 💡 팁

### ✅ 문제내용 작성 팁
- 문제는 명확하고 간결하게 작성하세요
- 법률 조문을 인용할 때는 정확하게 작성하세요
- 학생들이 이해하기 쉽게 작성하세요

### ✅ 선택지 작성 팁
- 각 선택지는 비슷한 길이로 작성하세요
- 명백하게 틀린 선택지는 피하세요
- 혼동하기 쉬운 개념을 활용하세요

### ✅ 해설 작성 팁
- 정답뿐만 아니라 오답인 이유도 설명하세요
- 관련 법 조문과 판례를 인용하세요
- 핵심 개념을 강조하세요
- 각 선택지별로 ①②③④ 번호를 달아 설명하면 좋습니다

### ✅ 키워드 작성 팁
- 검색에 도움이 되는 주요 단어를 입력하세요
- 너무 많이 입력하지 마세요 (3-5개 정도)
- 쉼표로 구분하세요

## ❓ 자주 묻는 질문

**Q: 엑셀 대신 구글 스프레드시트를 사용해도 되나요?**
A: 네! 구글 스프레드시트로 작성 후 "파일 > 다운로드 > Microsoft Excel (.xlsx)"로 다운로드하세요.

**Q: 선택지가 4개만 있으면 어떻게 하나요?**
A: 선택지5 칸은 비워두시면 됩니다.

**Q: 문제에 이미지를 넣을 수 있나요?**
A: 현재 버전에서는 텍스트만 가능합니다. 이미지 기능은 추후 추가 예정입니다.

**Q: 실수로 틀린 문제를 입력했어요.**
A: 개발자에게 문제 번호를 알려주시면 수정할 수 있습니다. 추후 관리자 페이지에서 직접 수정 가능하게 될 예정입니다.

**Q: 한 번에 몇 개까지 입력할 수 있나요?**
A: 제한은 없지만, 처음에는 10-20개 정도로 테스트해보고, 정상 작동하면 더 많이 입력하세요.
