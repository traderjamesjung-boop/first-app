## 문제 입력 방법 선택하기

### 언제 엑셀을 사용하나요? ✅

- 한 번에 **많은 문제**(10개 이상)를 입력할 때
- 이미 **워드나 PDF**에 문제가 정리되어 있을 때
- **엑셀이나 구글 스프레드시트**를 사용할 수 있을 때

### 언제 웹 페이지를 사용하나요? ✅

- **1-2개의 문제**만 빠르게 입력할 때
- 입력한 문제를 **즉시 확인**하고 싶을 때
- 엑셀보다 **간단한 입력 양식**을 선호할 때

## 방법 1: 엑셀로 한 번에 입력하기

### ✅ 1단계: 엑셀 양식 만들기

#### 엑셀이나 구글 스프레드시트를 열고 다음처럼 작성하세요:

**첫 번째 줄 (제목 행):**

```
시험유형 | 시험년도 | 문제번호 | 카테고리 | 문제내용 | 선택지1 | 선택지2 | 선택지3 | 선택지4 | 선택지5 | 정답 | 해설 | 판례 | 키워드 | 난이도
```

**두 번째 줄부터 (문제 입력):**

| 열 이름 | 입력 방법 | 예시 |
|--------|----------|------|
| 시험유형 | `공무원`, `변호사시험`, `사법시험`, `연습문제` 중 하나 | `변호사시험` |
| 시험년도 | 숫자만 입력 | `2023` |
| 문제번호 | 숫자만 입력 | `1` |
| 카테고리 | 한글로 자유롭게 | `형법총론` |
| 문제내용 | 문제 전체 텍스트 | `다음 중 옳은 것은?` |
| 선택지1~4 | 각 선택지 내용 (필수) | `형법은...` |
| 선택지5 | 5지선다면 입력, 4지선다면 비워두기 | (비워두기) |
| 정답 | 1, 2, 3, 4, 5 중 하나 | `4` |
| 해설 | 문제 해설 | `형법 제1조는...` |
| 판례 | 관련 판례 (선택) | `대법원 2008도10479` |
| 키워드 | 쉼표로 구분 | `행위시법,소급효` |
| 난이도 | `쉬움`, `보통`, `어려움`, `전문가` | `보통` |

### ✅ 2단계: 실제 예시 따라하기

```excel
시험유형    시험년도  문제번호  카테고리   문제내용
변호사시험   2023     1       형법총론   다음 중 형법의 시간적 적용범위에 관한 설명으로 옳지 않은 것은?

선택지1: 범죄 후 법률의 변경에 의하여 그 행위가 범죄를 구성하지 아니하거나 형이 구법보다 경한 때에는 신법에 의한다.
선택지2: 재판확정 후 법률의 변경에 의하여 그 행위가 범죄를 구성하지 아니한 때에는 형의 집행을 면제한다.
선택지3: 형법은 원칙적으로 행위시법주의를 취하고 있다.
선택지4: 신법이 구법보다 형이 중한 경우에도 신법을 적용하는 것이 원칙이다.
선택지5: (비워두기)

정답: 4

해설: 
형법 제1조 제2항은 "범죄 후 법률의 변경에 의하여 그 행위가 범죄를 구성하지 아니하거나 형이 구법보다 경한 때에는 신법에 의한다"고 규정하여 피고인에게 유리한 소급효를 인정하고 있습니다.

① 형법 제1조 제2항 전문에 해당합니다.
② 형법 제1조 제3항에 해당합니다.
③ 형법은 원칙적으로 범죄 시의 법률을 적용하는 행위시법주의를 취하고 있습니다.
④ 틀렸습니다. 신법이 구법보다 형이 중한 경우 구법을 적용합니다.

판례: 대법원 2008도10479 판결
키워드: 행위시법,소급효금지,형법총론,시간적적용범위
난이도: 보통
```

### ✅ 3단계: 파일 저장하기

1. 파일 이름: **형법문제_2023.xlsx** (원하는 이름으로)
2. 저장 위치: 바탕화면이나 문서 폴더
3. 형식: **Excel 파일 (.xlsx)**

**구글 스프레드시트 사용 시:**
- `파일` > `다운로드` > `Microsoft Excel (.xlsx)`

### ✅ 4단계: 개발자에게 전달하기

저장한 엑셀 파일을 개발자에게 전달하고 다음과 같이 요청하세요:

```
"이 엑셀 파일의 문제들을 데이터베이스에 추가해주세요."
```

**개발자가 실행할 명령어:**
```bash
cd backend
npm run seed:questions 형법문제_2023.xlsx
```

## 방법 2: 웹 페이지에서 하나씩 입력하기

### ✅ 1단계: 관리자 페이지 접속

1. 웹 브라우저를 열고 **형법 마스터** 사이트에 접속
2. **관리자 계정**으로 로그인
3. 상단 메뉴에서 **"문제 관리"** 클릭
4. **"새 문제 추가"** 버튼 클릭

### ✅ 2단계: 양식 채우기

화면에 나타나는 양식을 위에서 아래로 차례대로 채우세요:

#### 기본 정보
- **시험 유형**: 드롭다운에서 선택
- **시험 년도**: 2023 같은 숫자 입력
- **문제 번호**: 1, 2, 3... 순서대로
- **카테고리**: 형법총론, 형법각론 등
- **난이도**: 쉬움/보통/어려움/전문가 선택

#### 문제 내용
- 큰 텍스트 박스에 문제 전체를 입력하세요

#### 선택지
- 선택지 1~4: 각 보기 내용 입력 (필수)
- 선택지 5: 5지선다인 경우만 입력
- 정답 번호: 드롭다운에서 선택 (1~5)

#### 해설
- 문제에 대한 상세한 설명
- 각 선택지가 맞는지 틀린지 설명하세요

#### 추가 정보 (선택사항)
- 관련 판례: 대법원 판례 번호
- 키워드: 쉼표로 구분해서 입력

### ✅ 3단계: 저장하기

- 모든 항목을 확인하고
- 하단의 **"문제 추가하기"** 버튼 클릭
- 성공 메시지 확인!

## 문제 입력 후 확인하기

### ✅ 입력된 문제 보기

1. **"문제 목록"** 메뉴 클릭
2. 방금 입력한 문제 찾기
3. 문제 클릭해서 내용 확인

### ✅ 문제 테스트하기

1. **"문제 풀이"** 메뉴 클릭
2. 방금 입력한 문제가 나오는지 확인
3. 직접 풀어보며 확인

## 자주 묻는 질문

### ❓ Q1: 엑셀 파일을 만드는데 형식이 틀렸나요?

**A:** 가장 중요한 것은 **첫 번째 줄의 열 제목**입니다. 정확히 이렇게 입력하세요:

```
시험유형 | 시험년도 | 문제번호 | 카테고리 | 문제내용 | 선택지1 | 선택지2 | 선택지3 | 선택지4 | 선택지5 | 정답 | 해설 | 판례 | 키워드 | 난이도
```

띄어쓰기 없이 한 단어로 입력하세요!

---

### ❓ Q2: 선택지가 4개만 있어요. 선택지5는 어떻게 하나요?

**A:** 선택지5 칸은 **비워두세요**. 아무것도 입력하지 마세요.

---

### ❓ Q3: 문제에 줄바꿈을 하고 싶어요.

**A:** 
- **엑셀**: 셀 안에서 `Alt + Enter` (Windows) 또는 `Option + Enter` (Mac)
- **웹 페이지**: 그냥 Enter 키 누르면 됩니다

---

### ❓ Q4: 해설이 너무 길어요.

**A:** 길이 제한은 없습니다. 상세할수록 좋습니다! 학생들에게 도움이 됩니다.

---

### ❓ Q5: 실수로 틀린 문제를 입력했어요.

**A:** 개발자에게 문의하세요:
- 어떤 문제인지 (시험유형, 년도, 문제번호)
- 무엇을 수정해야 하는지

추후 관리자 페이지에서 직접 수정 가능하게 될 예정입니다.

---

### ❓ Q6: 판례나 키워드는 꼭 입력해야 하나요?

**A:** 아니요, 선택사항입니다. 하지만 입력하면:
- 판례: 학생들에게 더 좋은 학습 자료
- 키워드: 검색이 잘 됩니다

---

### ❓ Q7: 한 번에 몇 개까지 입력할 수 있나요?

**A:** 
- **엑셀**: 1000개도 가능하지만, 처음엔 10-20개로 테스트하세요
- **웹 페이지**: 하나씩 입력하므로 5-10개 정도 권장

---

### ❓ Q8: 엑셀과 웹 페이지 중 뭐가 더 좋나요?

**A:** 
- **엑셀**: 많은 문제를 한 번에 (10개 이상)
- **웹 페이지**: 급하게 1-2개 추가할 때

둘 다 사용해보고 편한 방법을 선택하세요!

---

### ❓ Q9: 이미지가 있는 문제도 입력할 수 있나요?

**A:** 현재 버전에서는 **텍스트만** 가능합니다. 
이미지 기능은 추후 업데이트 예정입니다.

---

### ❓ Q10: 문제가 제대로 입력됐는지 어떻게 확인하나요?

**A:** 
1. 웹사이트에서 "문제 목록" 확인
2. "문제 풀이"에서 직접 풀어보기
3. 개발자에게 확인 요청
