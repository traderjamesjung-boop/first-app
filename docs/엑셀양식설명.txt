==================================================
  형법 마스터 - 문제 입력 엑셀 양식
==================================================

📋 엑셀 파일을 만들 때 첫 번째 행에 다음 열 제목을 입력하세요:

시험유형 | 시험년도 | 문제번호 | 카테고리 | 문제내용 | 선택지1 | 선택지2 | 선택지3 | 선택지4 | 선택지5 | 정답 | 해설 | 판례 | 키워드 | 난이도

==================================================
  각 열에 입력할 내용:
==================================================

[시험유형] 
  - 공무원
  - 변호사시험
  - 사법시험
  - 연습문제

[시험년도]
  - 숫자만 입력 (예: 2023)

[문제번호]
  - 숫자만 입력 (예: 1, 2, 3...)

[카테고리]
  - 한글로 자유롭게 (예: 형법총론, 형법각론, 형사소송법)

[문제내용]
  - 전체 문제 텍스트

[선택지1, 선택지2, 선택지3, 선택지4]
  - 각 선택지 내용 (필수)

[선택지5]
  - 5지선다인 경우만 입력, 4지선다면 비워두기

[정답]
  - 정답 번호 (1, 2, 3, 4, 5 중 하나)

[해설]
  - 문제 해설 및 각 선택지 설명

[판례]
  - 관련 판례 (선택사항, 없으면 비워두기)
  - 예: 대법원 2008도10479 판결

[키워드]
  - 쉼표로 구분하여 입력
  - 예: 행위시법,소급효금지,형법총론

[난이도]
  - 쉬움
  - 보통
  - 어려움
  - 전문가

==================================================
  샘플 예시:
==================================================

시험유형: 변호사시험
시험년도: 2023
문제번호: 1
카테고리: 형법총론
문제내용: 다음 중 형법의 시간적 적용범위에 관한 설명으로 옳지 않은 것은?
선택지1: 범죄 후 법률의 변경에 의하여 그 행위가 범죄를 구성하지 아니하거나 형이 구법보다 경한 때에는 신법에 의한다.
선택지2: 재판확정 후 법률의 변경에 의하여 그 행위가 범죄를 구성하지 아니한 때에는 형의 집행을 면제한다.
선택지3: 형법은 원칙적으로 행위시법주의를 취하고 있다.
선택지4: 신법이 구법보다 형이 중한 경우에도 신법을 적용하는 것이 원칙이다.
선택지5: (비워두기)
정답: 4
해설: 형법 제1조 제2항은 "범죄 후 법률의 변경에 의하여 그 행위가 범죄를 구성하지 아니하거나 형이 구법보다 경한 때에는 신법에 의한다"고 규정하여 피고인에게 유리한 소급효를 인정하고 있습니다. 따라서 신법이 구법보다 형이 중한 경우에는 구법을 적용하는 것이 원칙입니다.
판례: 대법원 2008도10479 판결
키워드: 행위시법,소급효금지,형법총론,시간적적용범위
난이도: 보통

==================================================
  파일 저장 방법:
==================================================

1. 엑셀로 작성
2. 파일명: 원하는이름.xlsx (예: 형법문제_2023.xlsx)
3. backend 폴더에 저장
4. 개발자에게 업로드 요청

==================================================
  업로드 명령어 (개발자용):
==================================================

cd backend
npm run seed:questions 파일명.xlsx

또는 샘플 문제 생성:
npm run seed:questions sample
